  expertise.html              Expertise
  work.html                   Work (with filters)
  work-nasscom.html           Case: NASSCOM NTLF
  work-metfab.html            Case: Metfab Designs

Shared files
  assets/styles.css    all styling (brand colours are at the top as variables)
  assets/site.js       scroll motion, copy buttons, work filters, contact forms
  assets/fonts/        Hobart Days (Anek Latin loads from Google Fonts)

To publish: upload the whole folder to the web host's public folder (for example public_html),
keeping the folder structure as it is. index.html is the home page.
